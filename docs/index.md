# rust-annie documentation

**rust-annie** is a Python library for exact and approximate *k*-nearest-neighbour
search, implemented in Rust.

```bash
pip install rust-annie
```

- [User guide](user-guide.md): choosing an index, metrics, custom metrics, filters,
  persistence, threads, tuning HNSW, monitoring
- [API reference](api.md): every class, method and exception
- [Benchmarks](benchmarks.md): comparison with hnswlib, FAISS and NumPy, and how to
  reproduce it

Source code, issues and the changelog are on
[GitHub](https://github.com/Programmers-Paradise/Annie).
